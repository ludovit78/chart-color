# Chart Color extension

Sends the chord sheet on the current tab into Chart Color.

Works on Ultimate Guitar chord pages. Also tries E-Chords and Cifra Club.

## Chrome / Edge / Brave

1. Download this `extension` folder.
2. Open `chrome://extensions`
3. Turn on **Developer mode**
4. **Load unpacked** → pick the `extension` folder
5. Open a song on [tabs.ultimate-guitar.com](https://tabs.ultimate-guitar.com)
6. Click the Chart Color icon in the toolbar

## iPhone Safari

Safari cannot load this unpacked extension. Use the bookmarklet on the helper page instead:
https://ludovit78.github.io/chart-color/extension.html
