# Chart Color

Pianist chart tool: import a song, pick a style, get extra changes sitting on the correct words.

No staff notation. Output is a chord chart you can read at the piano, then export back to OnSong / ChordPro / aligned text / print-PDF.

## Live

https://ludovit78.github.io/chart-color/

Repo: https://github.com/ludovit78/chart-color

## Open it

Open `index.html` in a browser (Chrome, Edge, Firefox).

## Import

| Source | How |
| --- | --- |
| OnSong | Drop `.onsong` or paste. Bracketed chords (`[G]Amazing`) and chords-over-lyrics both work. |
| ChordPro | Drop `.cho` / `.chopro` / `.crd` / `.pro` or paste `{title:}` tags. |
| Ultimate Guitar | Copy the chord sheet as text, or save the page as PDF and drop it. |
| PDF | Drop a text-based chord PDF. Scanned image-only PDFs will come out empty — paste the text instead. |

## Styles

- **Bossa Nova** — ii–V–I into landings, maj9 / m9 / 9–13, tritone color
- **Smooth Jazz** — 9 / 11 / 13, slashy bass, secondary dominants
- **Gospel** — I7 into IV, passing dim, add2, walk-ups
- **Neo-Soul** — maj9, m9/m11, 7sus4, chromatic bass
- **Pop Ballad** — add9, sus, light passing ii
- **Funk** — 9, 7#9, 9sus4
- **Blues** — dominant I–IV–V, #9, dim approach
- **Latin / Samba** — maj7 / m7 with ii–V
- **R&B** — maj7 / m7, applied V, bass walks
- **Worship** — add2, sus holds, IV/I
- **Country** — triads first, I7 and vi only when useful
