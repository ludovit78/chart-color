Send a site chart into Chart Color

Open a chords page, run the helper, Chart Color opens with that song.

iPhone / Safari

  1. Hold this button and add it to Favourites / Bookmarks:

Send to Chart Color

  1. Open Ultimate Guitar (or another chords page).
  2. Tap the bookmark. Chart Color should open with the song loaded.

Laptop (Chrome / Edge / Brave)

  1. Download the extension folder.
  2. Go to chrome://extensions → Developer mode → Load unpacked → choose that folder.
  3. On a chords page, click the Chart Color toolbar button.
