Chart Color helper

This does not install from the Chrome store. Load it once on a laptop. After that, every Ultimate Guitar chords page gets an orange Send to Chart Color button.

Chrome / Edge / Brave

  1. Open the extension folder.
  2. Click the green Code button on the repo → Download ZIP. Unzip it.
  3. Go to chrome://extensions (Edge: edge://extensions).
  4. Turn on Developer mode (top right).
  5. Load unpacked → choose the unzipped extension folder (the one that contains manifest.json).
  6. Open a song chords page on Ultimate Guitar, not the search results.
  7. Tap the orange button at the bottom right, or the puzzle-piece Chart Color icon.

iPhone

Safari cannot load this unpacked extension. On the chords page: select the chart, Copy, open Chart Color, tap Paste clipboard.
